# Runtime Protocol V2 threat model

## Assets and boundaries

Protected assets include workspace files, Git state, process trees, containers, database credentials/data, browser sessions, OS authority, journals, evidence, provider credentials, and publication rights. The backend is authoritative for identity, entitlement, routing, inference, and provider secrets. The extension is authoritative for local capability truth, approvals, execution, cancellation, stale-state checks, and evidence.

## Primary threats and controls

| Threat                                     | Required control                                                                                         |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| Prompt injection requests a dangerous tool | Structured tool catalog, policy classification, exact approval, immutable safety rails                   |
| Confused deputy changes target or scope    | Account/workspace/target/policy epochs and target identity hash in every invocation                      |
| Path traversal, symlink escape, or TOCTOU  | Canonical URI containment, before-hash preconditions, transactional revalidation                         |
| Shell injection                            | Direct executable/argument contracts; shell text is not a tool input                                     |
| Secret disclosure                          | Secret Storage handles, environment-key denylist, result redaction and bounded JSON                      |
| Replay or duplicate events                 | Idempotency keys, ordered sequences, one-shot capabilities, non-repeatable effect blocking               |
| Target drift/reconnect                     | Capability and identity revalidation, epoch increment, cancellation and owned cleanup                    |
| Browser exfiltration                       | Isolated contexts, origin policy, explicit external navigation, download byte limits, sanitized evidence |
| Container/DB destructive action            | Ownership labels, statement classification, production denial, separate R4 approval                      |
| Elevation abuse                            | Signed single-operation envelope/receipt, executable and argument hashes, nonce/expiry, native consent   |
| Multi-agent races                          | DAG dependencies, write sets, leases, isolated worktrees, integrator-only publication                    |
| Journal theft/corruption                   | AES-256-GCM with Secret Storage key, strict schema, safe export, corrupt-store denial                    |
| Supply-chain substitution                  | Locked dependencies, SBOM, artifact hashes, reproducible package comparison, signed release evidence     |

## Immutable rails

Enterprise policy may narrow access but cannot permit unrestricted shell elevation, hidden reasoning export, provider-secret exposure, silent telemetry, implicit cross-target file transfer, automatic publication, or destructive unowned-process cleanup.

## Release blockers

Critical/high vulnerabilities, RCE, path escape, authorization bypass, stale-state races, secret leakage, data loss, replayed effects, or orphaned elevated helpers block release. Unsupported or untested platform paths must be labeled honestly rather than inferred from compilation.

## Attack surface added in 1.81.0 to 1.83.0

Each row names the control that exists in code. A control is listed only when
it was found in `src/`; gaps are stated under "Known gaps". All of these run
behind the same Runtime V2 policy gate, workspace trust, approval broker and
immutable rails as every other tool.

| Surface                                                                                           | Threat                                                                                                                                          | Controls that exist                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MCP servers (`runtime.mcp`, `core/mcp/*`, `infrastructure/mcp/*`)                                 | A hostile `.clawai/mcp.json` in a cloned repository starts a process or reaches an attacker host; a server returns oversized or injected output | Stdio servers start only in a trusted workspace and `cwd` must stay inside it. Remote URLs must be `https` (`http` only on localhost, `MCP_LOOPBACK_HOSTS`). `headers` may not carry `Authorization` or `Cookie`. `tools` and `call` are R3, so every call asks. Allow/deny globs by `name`, `command` and `url`, deny wins, in project and organization policy (`mcp-server-policy.ts`). Bounds: 128 KB config, 32 servers, 500 tools per server, 8 MiB per message, 48,000 characters of result text, 120 s call timeout (600 s max). User-level servers in `clawAI.mcpServers` are user-scope only and win a name clash. |
| MCP OAuth (`mcp-oauth.ts`, `mcp-oauth-service.ts`, ADR 0002)                                      | Authorization-code interception; token theft; redirect to an attacker                                                                           | PKCE, and the return goes to the one-shot loopback callback, not the URI handler (ADR 0001 keeps `vscode://` navigation-only). Tokens live in SecretStorage under `clawai.mcp.oauth.`, never in settings or files. Five-minute flow timeout; 60 s expiry margin.                                                                                                                                                                                                                                                                                                                                                            |
| Plugins (`plugin-manifest*.ts`, `plugin-path.ts`, `plugin-archive.ts`, `plugin-store.ts`)         | Zip-slip, oversized or hostile bundles; a plugin gaining execution the user did not grant                                                       | `clawai-plugin.json` is a strict schema (64 KB). Every contributed path must be a contained relative path: forward slashes only, no drive letter, no leading slash, no `..`; a backslash is refused rather than translated. At most 500 files, 10 MiB, depth 8. A plugin's MCP servers are declared, not started: only the MCP client starts them, so MCP policy and per-call approval apply. Plugin hooks use the lifecycle-hook schema (at most 20).                                                                                                                                                                      |
| Marketplaces (`plugin-marketplace*.ts`, `plugin-download.ts`)                                     | Substituted archive; untrusted publisher; SSRF-style source                                                                                     | Every catalog entry pins a `sha256` of the exact bytes; a mismatch refuses the install. An entry may also carry a detached Ed25519 signature checked against `clawAI.trustedPluginPublishers`; a missing or bad signature costs whatever `clawAI.pluginSignaturePolicy` says (`off`, `warn` as the default, `require`). Sources are an https `.zip`, a catalog-relative path or a local folder. `allowedPluginMarketplaces` in project and organization policy narrows which marketplaces may be used (absent means no restriction, present-but-empty refuses all).                                                         |
| Git marketplace clone (`plugin-git-marketplace.ts`, `plugin-git-clone.ts`)                        | Argument injection through a ref or URL; credential prompts; stale content                                                                      | Prefix `git+`; ref must match `^[A-Za-z0-9][A-Za-z0-9._/-]{0,199}$`. Cloned through the bounded command runner: no shell, allowlisted environment, `GIT_TERMINAL_PROMPT=0`, 120 s timeout, 64 KB output cap, shallow, replaced afresh on every open, removed on failure. Catalog entries are then sha256-checked like any marketplace.                                                                                                                                                                                                                                                                                      |
| Remote commands (`remote-command-policy*.ts`, `remote-command-loop.ts`, `agent-remote-client.ts`) | Another device or the server sends a command                                                                                                    | Text is untrusted and runs without a shell. Read-only allowlist only (`git status/log/diff/show/branch/remote/rev-parse`, `ls`, `dir`, `pwd`, `whoami`, `node -v`, `npm -v/ls/view`). Shell operators refused, 4,096 characters and 64 arguments at most, write flags refused. Local approval on the editor. A remote-control session key and a runner token are separate credentials; a runner token is revocable and stops working after heartbeat expiry.                                                                                                                                                                |
| Runner prompt jobs (`runner-prompt-policy*.ts`, `runner-prompt-executor.ts`)                      | A prompt routine drives an unattended machine                                                                                                   | Tool categories are limited to read, git, write and command, with an approval policy chosen at registration; a refused job exits 126.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Channels webhook (`channel-client.ts`, `channel-inbox-watcher.ts`, `channel-message-format.ts`)   | A forged or hostile event injects instructions                                                                                                  | The extension only polls the agent-service inbox; it never listens on a port. The webhook secret and signature format come from the backend (HMAC); verification is server-side. A message is put in the composer as a block that names its source, for the user to read before anything is sent; it is never executed. Poll cadence is bounded (60 s, backoff to 15 min, 5 failures, 240 polls).                                                                                                                                                                                                                           |
| Artifact publish (`artifact-publication.ts`, `artifact-tool-executor.ts`)                         | A secret leaves the machine on a public link                                                                                                    | Two-pass scrub (shared redactor, then the commit-path secret detector); a surviving credential blocks the publish. Binaries refused, 1 MiB cap, MIME by extension allowlist. Publishing is R-gated and approved. Blocked entirely under zero data retention. Sandboxing of the served page is a backend property and is not verifiable here.                                                                                                                                                                                                                                                                                |
| Browser coordinates (`browser-operation.ts`, `playwright-page-actions.ts`)                        | The model clicks something it never saw                                                                                                         | `click-at`, `type-text`, `scroll` and `observe` refuse out-of-viewport coordinates instead of clamping them. `observe` boxes are visible-only, bounded in number, names truncated. Screenshots are at most 8 MiB and are uploaded as backend files (refused under zero retention).                                                                                                                                                                                                                                                                                                                                          |
| Sandbox (`command-sandbox*.ts`)                                                                   | A command reads credentials or the network                                                                                                      | `clawAI.commandSandbox.mode` is off, auto, bubblewrap, seatbelt or docker; network is off by default (`allowNetwork`). Credential directories (`.ssh`, `.aws`, `.gnupg`, `.kube`, `.docker`, gcloud, gh, `.netrc`, `.npmrc`, `.pypirc`, `.git-credentials`) are hidden. Docker runs with a pids limit of 512 and the workspace at `/workspace`. A named mechanism the host lacks stops the command; it is never downgraded. On Windows `auto` reports none rather than calling a job object isolation.                                                                                                                      |
| Session worktrees, mailbox, scheduler                                                             | Runaway automation; cross-agent injection                                                                                                       | `exit` refuses uncommitted changes unless `discard` is set. Mailbox messages are redacted, deduplicated and quota-bounded. Scheduler runs only in trusted workspaces, one timer, 20 tasks, 5-minute floor, 100-run cap.                                                                                                                                                                                                                                                                                                                                                                                                     |
| Deferred tools                                                                                    | A tool smuggled into the catalog mid-run                                                                                                        | Loading changes the effective catalog hash only through the backend acknowledgement (`effectiveCatalogHash`); the admitted hash is unchanged and at most 16 tools load per call.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Telemetry                                                                                         | Content leaves in metrics; headers leak                                                                                                         | OTLP is opt-in through `clawAI.telemetryEndpoint`; custom headers are in SecretStorage (at most 32 entries), never settings. Queues are bounded (512 spans) with 3 attempts.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Dependency and security scan                                                                      | Scanner output as an injection vector                                                                                                           | osv-scanner, npm audit, pip-audit run through the bounded runner (180 s, 8 MiB); at most 200 findings kept.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Organization policy                                                                               | A forged policy widens access                                                                                                                   | Unsigned by design, but every field only narrows. `rules` deny/ask cannot allow. Failure to fetch fails open only for this endpoint.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

### Known gaps

- Publisher signatures default to `warn`, so an unsigned plugin installs with a
  warning unless the user sets `require`. The signature code
  (`core/plugin-signature*.ts`) was uncommitted in the working tree when this
  was written and is not in the 1.81 to 1.83 changelog; verify before relying on it.
- The channel webhook signature is verified by the backend; the extension does
  not re-verify it.
- Artifact page isolation (sandboxed origin) and post-turn redaction under zero
  data retention are backend controls, untested from this repository.
- Windows has no filesystem or network sandbox other than docker.
- Local Windows runs of native binaries can be blocked by Smart App Control,
  which affects test runs, not runtime posture.
