## Wave 0 - the audit

All 108 features were classified against the real code with file-and-line
evidence, in four documents under [`docs/parity/`](../parity/). "Present is not
wired" was applied throughout: a module with no callers is scaffolding.

| Class    | Count | Meaning                                     |
| -------- | ----- | ------------------------------------------- |
| SHIPPED  | 6     | Wired end to end and reachable by the model |
| PARTIAL  | 50    | Machinery exists with a named gap           |
| MISSING  | 50    | Nothing exists                              |
| CONFLICT | 2     | Contradicts an existing subsystem           |

The audit's dominant finding was not missing features. It was **a well-written
subsystem with zero callers while a document claims it shipped**, found five
times: `enterprise-policy.ts` against `CHANGELOG.md:942`, `compactedContext`
against `CHANGELOG.md:940`, `observability-service.setRemoteExport`, the model
catalog's `contextTokens` (dead data rather than a dead module), and
`chat-session.ts` `TranscriptEntry`. `AGENTS.md` now blocks writing a claim
ahead of a call site.

## Known limitations

- **F052** managed organization settings: no backend organization-policy
  endpoint and no key distribution exist. `enterprise-policy.ts` remains
  uncalled, and the changelog claim it contradicts is recorded rather than
  quietly left standing.
- **F059** conversation rewind: needs a backend contract.
- **F072/F073**: reversing a deliberate security decision; needs an ADR.
- **F104** backend half: `CodeReviewHandler` throws `SCAFFOLD-R3`.
- **Live-model matrix not run.** The pack asks for at least fourteen scenarios
  per feature, model-sensitive ones repeated three times across AUTO plus two
  providers plus a local model. For 108 features that is on the order of 4,500
  live runs against an authenticated backend. No batch is claimed DONE against
  that definition.
- Tasks and findings do not survive a restart; both are run-scoped and cleared
  on a workspace change by design.

## Not regressed

The superiority invariants held throughout: model-neutral routing, compare and
judge, cloud and local paths, the context receipt, the `@clawai` participant,
13 locales with RTL, attachments, effort and speed modes, and the Workspace
Trust, secret, path, CSP and atomic-edit boundaries. No coverage threshold was
lowered and no finding was suppressed.
