# Known Laboratory Limitations

- Active Runtime V2 runs are not reconstructed automatically after an extension-host or VS Code restart.
- The current prompt admission heuristic is not a durable structured requirement ledger.
- Vitest coverage enforces the 39 declared critical files, but is not whole-tree coverage.
- No committed chaos, fuzz, mutation, broad scale, resource-pressure, 8-hour, or 24-hour lane exists.
- Live provider/backend experiments require synthetic non-production credentials.
- Codex and Claude differential runs require current authorized products and official documentation.
- Public GitHub release, Marketplace publication, push, and production deployment remain approval gates.
