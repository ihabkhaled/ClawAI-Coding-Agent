## Which risks are open, who owns each, and what is the mitigation?

This is a register, not a plan. Each row cites its source. Read it with [Security](../security/README.md), which holds the controls, and [Drift](../drift/README.md), which holds the document conflicts.

How to read it:

- **Likelihood** and **Impact** are Low, Medium or High. They are this page's reading of the cited source on 2026-11-28. The owner has not confirmed them.
- **Owner** is a role named in the source. Where no source names one, the cell holds the gap marker.
- **Status**: `open` (known, not fixed), `mitigated` (a control exists), `accepted` (a document says the residual stays), `planned` (a future program, not built).

## What would close each open row

Each line names what would settle the row. R1 to R3, R12 and R17 come from the cited sources; R4, R11, R15, R18 and R20 are this page's suggestion. None of it exists yet.

- R1: an owner decision on the sandbox default, and a Windows-native answer ([sandbox page](../features/sandbox-redaction-secrets.md), open questions).
- R2: a host-lane run or a manual run recorded in a delivery report ([TESTING](../../TESTING.md)).
- R3: a live lane against a current backend for the 2026-09-30 routes, or a 404 fallback in the client ([ROADMAP](../../ROADMAP.md)).
- R4: a backend-side test or a written statement from the backend owner. The extension cannot prove it.
- R11: a named person or routine who reads GitHub alerts, and `security:check` run before every ship ([secure-every-change](../../../skills/secure-every-change/SKILL.md)).
- R12: the GitHub Support purge, requested by the owner ([project page](../project/README.md)).
- R15: a recorded count of people who can release, the token's rotation owner, and branch protection settings.
- R17: the backend routes, product decisions or platform change each row names ([PARTIAL_REMAINDERS](../../parity/PARTIAL_REMAINDERS.md)).
- R18: fixing the documents in [Security](../security/README.md) and [Drift](../drift/README.md), then recording the fix.
- R20: a documented step to enable the hooks after `npm ci --ignore-scripts`.

## When to change this page

A change that adds a boundary, a default, a dependency or a release step adds or updates a row in the same commit ([rule 18](../../RULES.md)). A risk nobody can name an owner for keeps the gap marker until the owner answers.
