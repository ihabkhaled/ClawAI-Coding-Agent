# Features

One page per feature area of the ClawAI Coding Agent: business why, product why, how it works, decisions,
dated history, tests and evidence, gaps and open questions. Written on 2026-11-28 from the code, `CHANGELOG.md`,
the parity audits and the git history (docs/adr/0009, rule 18). A page changes in the same commit as its code.
Part of the [project wiki](../index.md).

| Area                                                                                          | What it is for the user                                                                                                                                                                                                         |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Sign-in, accounts and sessions](accounts-and-sign-in.md)                                     | Connect the extension to your ClawAI account through the browser, without the extension ever seeing your password.                                                                                                              |
| [agent.team, sub-agents and orchestration](agent-team-orchestration.md)                       | The agent can hand parts of a big job to helper agents that run in parallel with less power than the lead, or you can run a plan file of agents in stages.                                                                      |
| [Billing, usage, quotas and receipts](billing-usage-receipts.md)                              | See what your plan allows and what you have used, and get a clear message when a plan limit or spent credit stops a request.                                                                                                    |
| [Channels, Slack, mobile pairing and QR](channels-mobile-pairing.md)                          | Outside systems can send alerts into the editor, run summaries can post to Slack, and the editor can be paired to a phone with a QR code.                                                                                       |
| [Chat and streaming](chat-and-streaming.md)                                                   | Talk to ClawAI models from inside VS Code: your message goes to the ClawAI backend and the answer streams back into the panel, in tabs that remember each conversation.                                                         |
| [Code review](code-review.md)                                                                 | The user can ask for a review of a selection or a whole change, get findings from several independent reviewer agents, run a security review, and post comments to GitHub or GitLab.                                            |
| [Context, receipts and the .clawai folder](context-and-clawai-folder.md)                      | Decide exactly which of your files the model sees, see a receipt of what was included and left out, and keep project rules in a `.clawai` folder.                                                                               |
| [Edits, review diff and undo](edits-review-undo.md)                                           | The agent proposes file changes; you see the diff, approve it, and can undo it.                                                                                                                                                 |
| [Headless CLI](headless-cli.md)                                                               | `clawai -p "<task>"` runs one agent task with no editor and no prompts, and exits with a code that says why it stopped.                                                                                                         |
| [knowledge.context, notes, rules, skills and memory](knowledge-notes-memory.md)               | The agent starts a run knowing your project's rules, can search them, keeps its own working notes, and reads your rule, skill and memory files in the order you set.                                                            |
| [Localization and accessibility](localization-accessibility.md)                               | Every visible string is translated into 12 languages besides English, and the panel works by keyboard, screen reader, narrow width, right-to-left and high contrast.                                                            |
| [Compaction, long sessions, retries and repetition detection](long-sessions-recovery.md)      | Long conversations are summarized before they fill the model window, and runs survive backend restarts, rate limits, busy providers, hung streams and a model stuck repeating itself.                                           |
| [MCP servers](mcp.md)                                                                         | The agent can call tools from Model Context Protocol servers (local programs or remote HTTP servers), with an approval for every call.                                                                                          |
| [Models, AUTO routing, compare and judge](models-routing-compare.md)                          | Pick a model yourself, let ClawAI choose (AUTO), or run several models side by side and have a judge rank them.                                                                                                                 |
| [Notebooks](notebooks.md)                                                                     | The agent can edit one cell of a Jupyter notebook without rewriting the file, and can run cells through the Jupyter extension.                                                                                                  |
| [Permission modes and approvals](permission-modes-approvals.md)                               | You choose how much the agent may do without asking; an organization can only make that stricter, never looser.                                                                                                                 |
| [Plugins, marketplaces and hooks](plugins-hooks.md)                                           | Users can install bundles of skills, commands, hooks, MCP servers and agents from marketplaces, and run their own commands at points of an agent run, all under approval and signature rules.                                   |
| [Release, versioning, ship and CI](release-ship-ci.md)                                        | Every change that reaches main is a numbered release: a commit hook bumps the version, `npm run ship` proves the commit on Linux first, CI runs split lanes, and a Release workflow publishes the same VSIX to the Marketplace. |
| [Runtime V2 runs, durable runs, resume and rewind](runtime-v2-runs.md)                        | The agent loop: a run that plans, calls tools under policy, survives interruptions, can be resumed, and can be rewound.                                                                                                         |
| [Sandbox, redaction and secret handling](sandbox-redaction-secrets.md)                        | Commands the agent runs can be confined to a sandbox, and secrets are masked or kept out of every place they could leak.                                                                                                        |
| [Scheduler, routines, cloud sessions and remote runners](scheduler-routines-cloud-runners.md) | Tasks and prompts can run later or on another machine: in-editor scheduled tasks, cloud routines, runners you own, remote control, remote jobs and cloud coding sessions.                                                       |
| [SDK](sdk.md)                                                                                 | A host-free library (`createAgent`, `runAgent`) that lets other programs drive the ClawAI agent runtime with their own tools, with no editor.                                                                                   |
| [task.plan, goals and flagship stages](task-plan-goals-flagship.md)                           | The agent keeps a plan, declares what "done" means, and cannot finish while a check is still open; a flagship delivery walks named stages and resumes after an interruption.                                                    |
| [Telemetry, OTLP, diagnostics and feedback](telemetry-diagnostics-feedback.md)                | Users can send run traces and metrics to their own OpenTelemetry collector, read a redacted diagnostic report before sending feedback, and see their usage.                                                                     |
| [Terminal integration](terminal.md)                                                           | The user can attach what a terminal printed to a request, and can run a whole agent request inside a terminal that reads like a build log.                                                                                      |
| [Testing lanes, live rounds and labs](testing-lanes-live-rounds.md)                           | The extension is tested in layers, from pure unit tests to a real VS Code driving a live ClawAI backend and real models, and a "lab" scores release readiness.                                                                  |
| [browser.page tool](tool-browser.md)                                                          | The agent opens your web app in a hidden browser, reads it, clicks, types, takes screenshots and reads console and network errors, to check what it just built.                                                                 |
| [Command, shell and process.watch tools](tool-command-shell-process.md)                       | The agent can run a program, keep a dev server or slow job running while it works, and (only if you switch it on) run a real shell script.                                                                                      |
| [workspace.file tool](tool-file.md)                                                           | The agent reads, searches, creates, changes, deletes and moves files inside your workspace folder, and can read PDFs, Office files and audio or video as text.                                                                  |
| [workspace.git tool](tool-git.md)                                                             | The agent can look at your repository, and with a second switch stage, commit, fetch, pull, push, switch branches, merge, rebase, stash and tag, without ever forcing or skipping hooks.                                        |
| [http.request tool](tool-http.md)                                                             | The agent can call your project's own API to test it and read the status, headers and body, with secrets hidden.                                                                                                                |
| [Pull requests and GitHub](tool-pull-requests.md)                                             | The agent can check if a branch is ready for a pull request, open one, watch its checks, fix red checks, and (in the panel and the CLI) view, review and merge an existing pull request with your approval.                     |
| [Web research and crawl](tool-web-research.md)                                                | The agent can search the web, read a page, read several pages of one site and extract a page with its links, all through the ClawAI research service.                                                                           |
| [Vision, attachments, documents and media read](vision-attachments-media.md)                  | Attach files and images to a message, let the agent look at a screenshot, and read PDFs, Office files and audio or video as text.                                                                                               |
| [Voice dictation](voice-dictation.md)                                                         | A microphone button in the composer turns speech into text, and when the editor cannot do that it says what will work instead.                                                                                                  |
| [Webview panel, views and commands](webview-views-commands.md)                                | The ClawAI chat panel, the sidebar views, the status bar, the keybindings and the 69 palette commands that make up the extension's visible surface.                                                                             |
| [Workspace, multi-root and worktrees](workspace-worktrees.md)                                 | The agent works inside one chosen workspace folder, can be granted extra output folders, can work in its own git worktree, and sub-agents can each get an isolated worktree.                                                    |
| [Zero retention and privacy](zero-retention-privacy.md)                                       | A zero data retention switch keeps run history in memory only and refuses every feature that needs the server to store content, and several other defaults keep private data off the wire.                                      |
